## Pre-share checklist

- [ ] Site deployed on Netlify and the live URL opens on a phone
- [ ] Replaced `forge-studio-pune.netlify.app` with the real URL in `index.html`, `robots.txt`, `sitemap.xml` and `site.js`
- [ ] Submitted a test trial form and saw it under **Forms → free-trial**
- [ ] Deleted the test submission
- [ ] Checked the layout at 360, 768, 1024 and 1440 px (browser dev tools)
- [ ] Tabbed through the whole page with the keyboard: skip link, menu, filters, plan switch, both forms
- [ ] Lighthouse (mobile, Incognito): Performance, Accessibility, Best Practices, SEO all 90+
- [ ] Shared the link in a WhatsApp or LinkedIn draft to check the preview image and title
- [ ] Ran the URL through Google's Rich Results Test to confirm the `HealthClub` data
- [ ] Added real screenshots to `docs/` and the README
- [ ] GitHub repository is public, with a description and the live link in "About"
- [ ] "Sample project" note visible in the footer
